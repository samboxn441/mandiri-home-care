MANDIRI HOME CARE MEDAN - WEBSITE DIPERBAIKI

FILE UTAMA: index.html

CARA UPLOAD KE GITHUB PAGES:
1. Buka repository mandiri-home-care-medan.
2. Upload seluruh isi folder hasil perbaikan ini ke root repository.
3. Pilih Replace jika GitHub meminta konfirmasi mengganti file lama.
4. Pastikan index.html, style.css, script.js, dan folder image berada di root.
5. Buka Settings > Pages; Source: Deploy from a branch; Branch: main (atau branch utama repository); Folder: /(root); Save.
6. Buka Actions dan tunggu Pages build and deployment sampai centang hijau.
7. Buka Settings > Pages > Visit site.
